# Day 27｜试用记录表模板

> 用法：对方每做完一步，Master（或对方自己在纸上写、你代录）填一行。**「原话」列最重要**，吐槽、疑问、语气词都照抄。
> 完成标准：一位没参与项目的真人完成核心流程（第 3 步新增 → 第 4 步刷新确认）。

## 一、试用者信息

| 项 | 内容 |
|---|---|
| 称呼（化名即可） | |
| 设备 | 例：iPhone 自带 Safari / 安卓微信内置浏览器 / Windows Chrome |
| 之前是否用过本站 | 应为「否」 |
| 开始时间 / 总耗时 | / 分钟 |

## 二、逐步记录

| 步骤 | 结果（完成/卡住/跳过/失败） | 用时 | 卡在哪（具体到点了什么按钮、屏幕显示了什么） | 试用者原话 |

| 2 看页面（用自己的话说这网站干嘛的） | | | 一句话理解： | |
| 3 让数据多一条（含糊点 1） | | | | |
| 4 刷新确认 | | | 在/不在/不确定： | |
| 5 改数据（含糊点 2） | | | | |
| 6 让数据消失 | | | | |
| 7 三个收尾问题 | | | 最好找：；最别扭：；以为坏了： | |

## 三、按步骤统计（对方做完后填）

- 谁卡住了：第 ___ 步，共 ___ 人卡住
- 谁写下了「找不到 / 不知道点哪」：第 ___ 步
- 谁出现了报错弹窗（抄下报错内容）：第 ___ 步
- 第 4 步刷新后数据丢失的人：___ 人（**出现即为 P0**）
- 全程无人求助完成的人数：___ 人

## 四、截图清单（今日要交的第一张截图来源）

- [ ] 对方设备上「核心数据页面」的画面（首页价格列表）
- [ ] 对方设备上「完成核心操作后」的画面（检查台新增记录成功 / 刷新后仍在）
- 合成进试用记录截图即可，图里要能看到是对方的设备（时间/电量/浏览器样式均可作证）
