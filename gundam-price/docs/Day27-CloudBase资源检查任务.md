## 二、导出数据留底（走「备份」或数据编辑器，约 5 分钟）

> 你当前已在 SQL 型数据库的数据编辑器里（能看到 kits / kit_prices / checkins 三张表）。

**路径 A（先试）：平台手动备份**
1. 左栏下方「平台管理」区点 **「备份」**。
2. 看页面上有什么：
   - 有 **「手动备份 / 创建备份」** 按钮 → 点它，按默认确认，等备份完成。
   - 备份列表里若有 **「下载」** → 下载到本机，存进项目 `db\backup\`，命名 `backup-2026-10-26`（按实际扩展名）。
   - 若**没有**下载选项（备份只能用于平台内恢复）→ 记下「已创建手动备份 1 份」也算留底达成，同时走路径 B。

**路径 B（备用）：数据编辑器逐表导出**
1. 回到你截图这个数据编辑器页面（左栏「数据管理 → 表」，选中表名，右侧出数据）。
2. 逐张导 `checkins`（检查台记录，最重要）、`kit_prices`、`kits`：
   - 在表格上方工具条找导出入口：一般在 **「···」更多菜单**、或右下角 **「数据 / 定义」** 切换条附近、或筛选按钮旁的下拉里。
   - 找到后选 CSV，确认导出，下载。
3. 文件存进项目 `db\backup\`，命名 `backup-2026-10-26-<表名>.csv`。
4. **验证**：记事本打开 `...checkins.csv`，能看到打卡记录内容 = 成功。
