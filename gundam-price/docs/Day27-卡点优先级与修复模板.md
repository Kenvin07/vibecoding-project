# Day 27｜最高优先级卡点筛选 + 修复提示词模板 + 复验任务

> 收到试用记录后由 Master 填写。**修复只修一个**：今天不做大改、不加新功能。

## 一、怎么选「最高优先级」

按下面的顺序判断，命中第一条就停，那就是今天要修的：

1. **P0｜数据丢了**：第 4 步刷新后，有人记录「不在」→ 数据可靠性问题，直接选它。
2. **P0｜完全走不通**：有人在第 3 步（新增）「找不到 / 失败 ×2」，导致核心流程没完成 → 选它。
3. **P1｜卡的人最多**：统计「逐步记录」里卡住人数最多的那一步（≥1 人就算）。
4. **P1｜含糊点失守**：【含糊点 1】（第 3 步入口）或【含糊点 2】（改数据的操作）上有人写「不知道点哪」→ 说明文案不可发现，选它。
5. **P2｜纯文案困惑**：有人完成了全流程但某一步「以为坏了 / 最别扭」指向同一处文案 → 记录下来，归入下轮，今天不修。

选择结论（填）：

- 卡点位置：第 ___ 步，具体位置（哪个页面、哪个按钮/文案）：
- 命中上面第 ___ 条规则
- 一句话描述：试用者在________时，期望________，实际________。

```

要求：
```
